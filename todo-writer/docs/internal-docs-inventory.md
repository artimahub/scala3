# Non-user-facing Scaladoc in the 12 documentation PRs

Generated by `todo-writer/scripts/split-internal-docs.py report`.

A declaration is **user-facing** when the published Scaladoc renders it:
public, or plain `protected`. Everything else is hidden by scaladoc's
`isHiddenByVisibility` (`scaladoc/src/dotty/tools/scaladoc/tasty/SymOps.scala:126`),
which drops every `Visibility.Private(_)` - qualified or not - plus
`protected[this]` and `protected[x]`, unless `-private` is passed.
`includePrivateAPI` defaults to false and no build in this repo sets it.
A member nested in a hidden container is itself unreachable, so it counts
as hidden even when it carries no modifier of its own.

## Caveats

The classifier is a regex plus an indentation-based scope walker, not a
compiler front end. Expect a small error rate on unusual layouts. The
`split` subcommand does not rely on the classification being perfect: it
verifies that the two resulting trees recombine to exactly the current
tree, that each rewritten branch is still comment-only against its merge
base, and that no `TODO FILL IN` marker reappears.
